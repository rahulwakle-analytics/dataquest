# DataQuest

Learn. Practise. Prove Your Skills. A practice platform for data analytics (Excel, SQL, Power BI, Python, Tableau).

This repository currently contains **Phase 1**: brand, design system, public site, learning paths and topic pages.

## Run it

```bash
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_SITE_URL for production
npm run dev                  # http://localhost:3000
npm run build && npm start   # production build
```

Requires Node 18.18 or newer. No other services are needed for Phase 1.

## Stack

Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Radix primitives with shadcn-style components
(`src/components/ui`), Geist font, next-themes.

## Structure

```
src/app                 routes: /, /paths, /paths/[tool], /paths/[tool]/[topic], /projects, /pricing, sitemap, robots, OG image
src/components/ui       Button, Badge, Card, Tabs, Accordion, Progress
src/components/home     interactive product preview, FAQ
src/components/learn    code block, knowledge check, practice question, path card, topic list
src/content             paths.ts (outline), lessons/*.ts (lesson content), projects.ts
src/lib                 site config, progress store, syntax highlighter
```

Design tokens live in `src/app/globals.css` (CSS variables for light and dark) and are mapped in `tailwind.config.ts`.

## Adding a lesson

Add an entry keyed `"<tool>/<topic-slug>"` to a file in `src/content/lessons` using the `Lesson` type. The topic page,
path counts, sitemap and "In development" labels update from the data.

## Status

Working:
- Homepage, navigation, light/dark theme, responsive layouts
- Five learning paths with 65 outlined topics and 32 full lessons: all 16 SQL topics and the complete Beginner level
  of Excel, Power BI, Python and Tableau. Every lesson has objectives, interview questions and a next-lesson link
- **Excel practice engine** (`src/lib/sheet`): a formula parser and evaluator written for this project. It supports
  arithmetic, comparisons, text joining, relative/absolute/mixed references, ranges, table (structured) references
  and about 30 functions. A learner's formula is calculated, copied across the fill range with references adjusted
  as Excel would, and compared with the reference solution on the sample data and on extra test cases.
  It is not Excel and does not open workbooks.
- **Sort and filter exercises** (`src/lib/table-practice.ts`): the table the learner produces is compared with the goal view
- Progressive hints, solutions on request, knowledge checks; one lesson template for every path
- Dashboard at `/dashboard`: topics completed, exercises solved, learning history
- **Career layer**: `/explore` (the profession, four workplace scenarios, sourced salary ranges), `/roadmap`
  (nine stages with completion tracking) and `/career` (resume, portfolio and LinkedIn checklists, interview
  question bank, self-assessed mock interview, case studies, role profiles). Content lives in `src/content/career.ts`.
  Salary figures carry their source and the date checked; update them there.
- **Practice Lab** (`/practice`): a hub linking to three playgrounds —
  - **SQL Playground** (`/practice/sql`): 15 challenges run on DuckDB WebAssembly in the browser
    (`src/lib/sql/engine.ts`). Read-only, one statement, 8 second limit, 1,000 row cap. A submission is compared
    with the reference query on two datasets. A schema/type explorer, a Copy SQL button and sample query chips
    sit alongside the editor. The engine files are copied from node_modules to `public/duckdb` by
    `scripts/copy-duckdb.mjs` before dev and build.
  - **Excel Playground** (`/practice/excel`): a fully editable, click-any-cell spreadsheet grid
    (`src/components/practice/sheet-editor.tsx`) built on the same formula engine as the lesson exercises, now
    extended with `SUMIFS`, `COUNTIFS`, `AVERAGEIFS` and `XLOOKUP`. 10 challenges (`src/content/sheet-challenges.ts`)
    including a pivot-style multi-cell summary, each checked by computed value against a reference formula
    (`src/lib/sheet/playground-check.ts`), never by string match — plus 2 sort-and-filter exercises on the existing
    table-practice engine.
  - **Power BI Practice Lab** (`/practice/powerbi`): 14 auto-checked, multiple-choice exercises
    (`src/content/powerbi-practice.ts`) across data modelling, relationships, DAX, measures vs. calculated columns,
    KPI calculation, dashboard design and report interpretation — clearly labelled as simulated practice, not a
    Power BI Desktop replica.
- **Dataset library** (`/datasets`): eight synthetic datasets generated by `npm run datasets` (seeded, reproducible)
  into `public/datasets`, with a manifest in `src/content/datasets.generated.json`
- **Projects** (`/projects`): five briefs, each with per-task hints, an expected-output description and a worked
  solution, a download link to the matching real dataset, self-ticked per-task completion
  (`project-{slug}-task-{i}`, saved separately from verified lesson/practice progress), and a "Portfolio
  deliverables" list. The Projects stage on `/roadmap` reads these same per-task ticks — it only marks a project
  done once every one of its real tasks is ticked on its own page, not from a click on the roadmap itself.
- Progress saved in `localStorage` (validated lesson/practice progress and self-ticked checklists are stored
  separately; the Projects roadmap stage bridges the two by reading real per-task ticks rather than its own)
- Per-page metadata, canonical URLs, JSON-LD, sitemap, robots.txt, Open Graph image

## Content checks

```bash
npm run verify
```

Runs engine unit tests (including SUMIFS/COUNTIFS/AVERAGEIFS/XLOOKUP) and, for every interactive exercise —
lesson practice, Excel Playground challenge, sort/filter challenge and Power BI exercise — checks that the
reference solution gives the hand-written expected values, passes its own test cases, and that each listed wrong
answer is rejected.

Not built yet: accounts and synced progress (Supabase), payments, admin CMS, analytics, XP streaks/leaderboards,
and stronger roadmap completion rules for non-lesson stages that have no gradable content yet (Statistics,
Interview Prep, Job Readiness). Nothing in the UI claims these are live.

Known limits: answers and solutions ship in the page bundle and are checked in the browser (SQL on a real DuckDB
engine, Excel on this project's own formula engine, Power BI against one correct option), and progress is per
browser. Both move server-side with accounts. Power BI exercises are multiple-choice by design — nothing here
executes live DAX or opens Power BI Desktop.

Configuration left empty on purpose: Pro price and social links in `src/lib/site.ts`.
